# College Geeks - Project Context

## Vision
Build a college-themed social strategy game inspired by classic campus simulators while establishing its own identity.

## Core Loop
Jobs -> Cash -> Tower -> Allies -> Stats -> PvP -> Cash.

## Core Stats
- Power
- Smartness

## Progression
- No XP
- No Levels
- Progression comes from Tower expansion and stronger Allies.

## Current Sprint
Sprint 1 Preparation

## Tech Stack
- Flutter
- NestJS
- PostgreSQL (Supabase)
- Prisma

## Rules for AI
- Read all docs before coding.
- Never invent gameplay features.
- Keep business logic on the backend.
- Make systems configurable.
- Build modularly so future systems plug in without rewrites.
