# College Geeks Game Design Bible

## Version
Alpha 0.1

## Core Loop
Jobs -> Cash -> Buy Tower Rooms -> Hire Allies -> Gain Power/Smartness -> PvP -> Earn Cash -> Repeat

## MVP Systems
- Authentication
- Player
- Tower
- Allies
- Jobs
- PvP
- Global Chat
- Leaderboards

## Core Stats
- Power
- Smartness

## PvP Actions
- Punch (Power)
- Face Off (Smartness)

## Energy
- Max: 10
- Regen: 1 every 7 minutes
- Cost: 1 per PvP action

## Progression
No XP. No player levels. Progression comes from Tower expansion and stronger Allies.
