# College Geeks Flutter client

## Run

From `mobile/`:

```bash
flutter pub get
flutter run --dart-define=API_URL=http://localhost:3000
```

For an Android emulator, the host machine is usually `http://10.0.2.2:3000`.

The current client includes login/registration, the home dashboard, live job countdown/progress, energy regeneration countdown, tower/allies, opponent search, and PvP.
